# Wireframes for Cooperative Bank Website

## 1. Overview

This document defines the visual layout and structure for the cooperative bank website across desktop and mobile devices. The wireframes are based on the finalized PRD and design system and are designed for a static, multilingual, mobile-first banking website in English and Kannada.

The wireframes focus on trust, clarity, usability, and financial credibility while ensuring smooth navigation on responsive screens.

---

## 2. Wireframe Conventions

- Desktop wireframes are described as full-page section layouts.
- Mobile wireframes are described as stacked, single-column flows prioritizing readability and quick access.
- Design should be clean, trust-oriented, and banking-appropriate.
- Content hierarchy must prioritize key actions: products, branches, contact, grievance.
- All sections should support English and Kannada content without layout breakage.

## 10. Shared Wireframe Rules Across Pages

### Desktop Rules
- Use clear left-to-right hierarchy with wide whitespace
- Use 2–3 column grid layouts where appropriate
- Keep section balance consistent and professional
- Highlight only a few important CTAs per page

### Mobile Rules
- Use stacked layouts with strong readability
- Keep key actions near the top of the page
- Use tap-friendly cards and buttons
- Avoid dense tables and long text blocks on small screens

### Bilingual Layout Rules
- Leave enough space for Kannada text expansion
- Avoid text truncation in navigation and CTA labels
- Ensure cards and buttons can accommodate longer translations
- Maintain alignment across English and Kannada versions

## 11. Summary

These wireframes provide the static page structure for the cooperative bank website across desktop and mobile layouts. They follow the final PRD, design system, and mobile-first requirements while remaining suitable for both English and Kannada content and a static Next.js implementation.
